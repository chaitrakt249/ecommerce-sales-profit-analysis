# Superstore Sales & Profitability Analysis — Power BI

## Project Overview
An interactive Power BI dashboard built using the Sample Superstore dataset to analyse sales, profitability, customer segments, and product performance.

## Tools Used
- Power BI Desktop
- DAX
- Sample Superstore dataset

## Key Performance Indicators (KPIs)
- Total Sales
- Total Profit
- Total Orders
- Profit Margin

## Dashboard Visualisations
- Monthly Sales Trend
- Sales by Category
- Profit by Category
- Sales by Customer Segment
- Profit by Customer Segment
- Top 10 Products by Sales
- Bottom 10 Products by Profit

## Interactive Filters
- Year
- Category
- Customer Segment
- Region

## Business Objective
Identify sales trends, profitable categories, customer segments, and products that may require further profitability investigation.

## Conclusion
This project demonstrates dashboard development, data visualisation, and business-focused sales and profitability analysis using Power BI.
