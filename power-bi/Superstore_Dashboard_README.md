# Superstore Sales & Profitability Analysis — Power BI

## Project Overview

An interactive Power BI dashboard built using the Sample Superstore dataset to analyze sales, profitability, customer segments, regional performance, and product performance.

The dashboard is part of an end-to-end data analytics project that also includes Python data cleaning, business analysis, and SQL analysis.

## Tools Used

- Power BI Desktop
- DAX
- Sample Superstore dataset

## Key Performance Indicators (KPIs)

- Total Sales
- Total Profit
- Total Orders
- Profit Margin

## Dashboard Visualizations

- Monthly Sales Trend
- Sales by Category
- Profit by Category
- Sales by Customer Segment
- Profit by Customer Segment
- Regional Performance
- Top 10 Products by Sales
- Bottom 10 Products by Profit

## Interactive Filters

- Year
- Category
- Customer Segment
- Region

## Business Objective

The dashboard helps identify:

- Sales trends
- Profitable categories
- Customer segment performance
- Regional performance
- High-performing products
- Loss-making products requiring further investigation

## Business Questions Answered

- How are sales changing over time?
- Which categories generate the most profit?
- Which customer segments contribute the most sales and profit?
- Which products generate the highest sales?
- Which products generate the lowest profit?
- How does performance vary across regions?

## Conclusion

This dashboard demonstrates the use of Power BI and DAX to transform transactional data into an interactive business reporting solution.

The dashboard allows users to explore sales and profitability from multiple business perspectives and identify areas requiring further investigation.
