# Data Dictionary

| Field | Meaning | Type |
|---|---|---|
| Row ID | Unique transaction-row identifier | Integer |
| Order ID | Customer order identifier | Text |
| Order Date | Date the order was placed | Date |
| Ship Date | Date the order shipped | Date |
| Ship Mode | Shipping service level | Text |
| Customer ID | Customer identifier | Text |
| Customer Name | Customer name | Text |
| Segment | Customer segment | Text |
| Country | Country | Text |
| City | Customer/order city | Text |
| State | Customer/order state | Text |
| Postal Code | Postal code | Numeric/Text |
| Region | Geographic region | Text |
| Product ID | Product identifier | Text |
| Category | Product category | Text |
| Sub-Category | Product sub-category | Text |
| Product Name | Product description | Text |
| Sales | Revenue recorded for transaction row | Numeric |
| Quantity | Units sold | Integer |
| Discount | Discount rate | Decimal |
| Profit | Profit recorded for transaction row | Numeric |
